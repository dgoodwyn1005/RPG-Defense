🛡️ RPG Defense

RPG Defense is an action-packed defense game where protecting the main chest is your only mission — and your life depends on it.

Fight off relentless enemies, strategically place towers, and survive dynamic day–night cycles in this fast-paced RPG defense experience.

🎮 Features

8-Directional Player Movement
Smooth and responsive movement in all directions.

Upgradeable Player Stats
To build upon self as game progresses

![Screenshot](/Screenshot_UpgradeMenu)

Multiple Attack Methods:

  Melee combat
  Bombs
  Knife throws

Tower Defense Mechanics
Place towers that automatically track and shoot enemies.

8+ Enemy Types
Each with unique movement and attack patterns.

![Gameplay Screenshot](/Screenshot_Gameplay)

Dynamic Day & Night System
Gameplay changes based on time of day.

Complete Sound System
Full audio experience with user-controlled sound settings.
